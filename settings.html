                    Persistent Maps
                    

                

                

                    

                        

                            Persistent maps for dungeons and significant interiors (room-scale) and settlements (district-scale). Ordinary settlement buildings stay on their district until CreateAreaMap explicitly promotes one. Map Architect creates the first map on its own connection; Map Updater and Map Evolution share a second connection for occupancy and off-screen change.

                                Map Architect
                                

                            

                            

                                

                                    

                                        When the narrator first enters an unmapped dungeon or settlement, this dedicated agent runs once. Dungeons get a complete room-scale map; towns and cities get a district-scale map. The architect validates every passage and entity reference, stores it in the root Location entry, and returns a compact private version to the narrator.
                                    

                                    Opener
                                    
                                    
                                    

                                        Text command: the GM must output only a [CREATE_AREA_MAP]...[/CREATE_AREA_MAP] block and stop. Map Architect then runs and the narrator continues from the entrance. Does not replace the tool path — pick one opener.

                                Map Updater
                                

                            

                            

                                

                                    

                                        After a map exists, this dedicated pass keeps occupancy current. It does not record NPC biographies or relationships — those stay on the Lorebook Agent. Uses the Map Updater & Evolution connection. Default is every turn, so Lorebook Agent can stay on a slower cadence.

                                Map Evolution
                                

                            

                            

                                

                                    

                                        Separate from occupancy. Advances mapped sites off-screen on in-world time. During an ordinary interval, site-exit, or manual pass, each map also interprets any relevant unconsumed World Report prose. Reports never trigger an immediate map fan-out. Uses the Map Updater & Evolution connection.

                    World Progression
                    

                

                

                    

                        

                            World Progression automatically generates off-screen world simulation reports at a fixed in-world time interval.
                            Reports are written by a standalone LLM pass and stored in the {prefix}_World lorebook.
                            The trigger is deterministic — JavaScript checks the [TIME] block after every State Tracker update;
                            the AI only writes the report, never decides whether to generate one.
                        


                        
                        

                            

                                
                                Quick Start Guide
                                

                            

                            

                                
Creating a World Skeleton is optional but recommended. It seeds places and wider-world premises beyond the player's immediate surroundings. World Progression later reads the full lore dossier for each selected location, but never receives its hidden map.

                                
    
                                    
  1. Create the Skeleton Source: Write anything from a short thematic seed to a granular world description. Auto-Generate safely extracts only a generalized world backdrop from recent chat, without carrying named story entities into the skeleton. You can also source existing lorebooks below.
    2. 
                                    
  2. Generate the Skeleton: Click Generate Skeleton. Locations become potential macro-simulation subjects; factions and conflicts provide wider-world context. Named entities may inform a location dossier but are never advanced independently by World Progression.
    3. 
                                    
  3. Set up Location Rotation: Choose how many locations a report covers. The oldest-unadvanced locations are selected first, with optional randomization only among equally old candidates.
    4. 
                                    
  4. Generate the First Report: Trigger a report immediately using Generate Now, or let it fire automatically. Its prose biases the narrator immediately; relevant maps realize it later when their normal Map Evolution pass runs.
    5. 
                                

                                

                                    
Miscellaneous

                                    
    
                                        
  • World Progression may read named people, buildings, and sublocations as constraints inside a location dossier, but does not advance those granular entities.
    • 
                                        
  • 24h seems to be a decent interval for World Report auto-generation, but you are encouraged to experiment with shorter intervals (or longer, for that matter).
    • 
                                        
  • You can always also trigger World Progression manually whenever you like.
    • 
                                        
  • Injection Position affects the prominence of World Reports (adjustable from Context Injection Settings below). The lower the report is positioned (closer to the most recent message), the more prominent the report will be to the narrator.

                    Adventure Companion
                    

                

                

                    

                        
Open Adventure Companion with the CHAT button at the top of the State Tracker. It can help with your adventure when TUTORIAL MODE is enabled, getting you to grips with the extension. In this mode, it has access to robust documentation.

Otherwise, it's there if you just feel like chatting about your adventure or brainstorm, etc. You can also ask it to make changes in the State Tracker, Lorebook Agent, or Map Updater, and it can take actions for you if you ask it to (by typing messages or making CYOA mode choices for you.)
